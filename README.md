# Solar Dashboard

A simulated solar power generator monitoring dashboard, built as a learning
project to practice Claude-assisted development, Git/GitHub workflows, and
automated testing.

## What this is

A web-based dashboard that displays mock telemetry for a simulated solar
power system. There is no physical hardware involved — all data is
generated by a simulation.

Simulated system specs:
- Solar panel capacity: 10 kW
- Battery capacity: 10 kWh
- Inverter capacity: 10 kW
- Load: cycles between 1–10 kW, changing every 3 seconds

## Project status

- ✅ Frontend dashboard with mock telemetry (client-side simulation)
- ⬜ Backend (FastAPI) serving real telemetry via API
- ⬜ Automated tests (pytest) for simulation logic
- ⬜ Frontend wired to backend instead of client-side mock data

## Running the frontend

The frontend currently runs entirely in the browser with no backend
dependency.

1. Open the `frontend/` folder in VS Code
2. Install the **Live Server** extension (if not already installed)
3. Right-click `index.html` → **Open with Live Server**

This avoids the `file://` security restrictions some browsers apply when
opening HTML files directly.
